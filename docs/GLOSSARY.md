# A few words, in ordinary English

[Back to the guide](../README.md)

You can look these up as needed. There is no need to memorise them first.

| Word | Meaning here |
| --- | --- |
| VS Code | Visual Studio Code, the application where you open the project and work with an assistant. |
| Extension | An add-on installed inside VS Code, such as Codex or Claude Code. |
| AI agent / assistant | An AI tool that may explain work or carry out tasks, depending on its available tools and permissions. |
| Workspace | The folder or folders currently open in VS Code. |
| Markdown / `.md` | A text format for headings, lists, and documents, used throughout this guide. |
| Git | The tool that records file changes as checkpoints on your computer. |
| GitHub | An online service that hosts Git repositories and provides collaboration tools. |
| Repository / repo | A project's files together with their Git history. |
| Clone | Make a local working copy of a repository and connect it to the source. |
| Save | Write edits into a file on your computer. |
| Stage | Select the version of a change to include in the next Git checkpoint. |
| Commit | A recorded checkpoint, with an author and a message. |
| Diff | A comparison showing changes between versions. |
| Branch | A separate line of work within the project. |
| `main` | A common name for the team's agreed branch; projects can use another name. |
| Push | Upload local commits to the shared repository. |
| Pull | Bring changes from the shared repository into your current local branch. |
| Pull request / PR | A proposal to combine changes from one branch into another, with space for review. |
| Merge | Combine one branch's changes into another. |
| Conflict | Overlapping changes that need an explicit resolution. |
| Terminal | A panel where commands can be typed or run by the assistant. |
| Command Palette | VS Code's searchable list of actions, available through the View menu. |
| Private repository | A hosted repository with restricted access; authorised collaborators and services can still access it. |

Technical reference: [VS Code's source-control overview](https://code.visualstudio.com/docs/sourcecontrol/overview) and [GitHub's beginner introduction](https://docs.github.com/en/get-started/using-github/hello-world).
