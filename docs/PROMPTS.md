# Requests you can copy

[Back to the guide](../README.md)

Use these in the installed assistant with the intended project folder open. Replace descriptions with your task. The assistant's ability to act depends on its tools and access.

## Organise an existing project

```text
Look at this project and explain what is here in plain English.
Suggest a simple folder structure for our work. Show me the proposed
file moves before doing them. Preserve all existing content.
```

## Draft a document

```text
Read brief.md and draft three options in copy.md.
Keep facts from the brief separate from suggestions. Mark anything
that needs confirmation. Do not invent client approvals or claims.
```

## Review an AI edit

```text
Show me which files you changed and summarise the difference.
Explain any factual assumptions. Tell me how I can inspect the result
myself. Do not treat your own review as someone else's approval.
```

## Save my work

```text
Check the current Git state and show me the files changed by this task.
Review those changes for accidental private material. Commit only the
agreed task files with a clear message. Tell me whether that checkpoint
is only on this computer or also uploaded to GitHub.
```

## Resume work

```text
Read our project README and setup-progress.md if present. Inspect the
actual files and Git state. Explain what is complete, what needs checking,
and the next small action. Do not assume you have earlier chat history.
```

## Propose work for a colleague

```text
Help me put this change on a separate branch and open a pull request.
Check existing work first. Verify the destination and changed files.
Give the reviewer a short explanation of what changed and why.
Leave merging to the authorised reviewer.
```

## Get help with an error

```text
I expected [describe the result], but I saw [paste the error text].
I use [Windows/Mac/Linux] and [assistant name].
Check the cause before changing anything. Preserve my files and local
edits. Give me one next step and explain what success would look like.
```

Remove passwords, tokens, personal information, and confidential content before pasting error output or sharing a screenshot.
