# Instructions for assistants working on this repository

This is a public, beginner-facing guide to AI-assisted teamwork. Use plain English and preserve a short route to a working AI extension before introducing Git collaboration.

- If tutoring a reader, read AI-GUIDE.md and follow the relevant guide pages. Do not assume you can access their computer or earlier chat history.
- If maintaining the guide, check product instructions against current official documentation. Distinguish verified product behaviour from suggested workflows and untested examples.
- Preserve unrelated edits. Keep the fictional example free of real client or account information.
- Review changed files, local Markdown links and anchors, and formatting. State the scope of verification honestly.
- Never infer that a checkpoint, push, client approval, and campaign publication are the same action.
- Do not add claims of mathematical fact without a defensible reference and explicit hypotheses. Do not present speculation as established fact.
