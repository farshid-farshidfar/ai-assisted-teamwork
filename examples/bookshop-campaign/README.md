# Practice campaign: a bookshop weekend

**Fictional example. No real business, client, or approval is represented.**

Goal: help a five-person team practise agreeing on a brief, proposing copy, and recording a decision.

- [Brief](brief.md): what the team is trying to make.
- [Copy](copy.md): draft headlines for review.
- [Design links](design-links.md): where reviewers find the artwork.
- [Decisions](decisions.md): a place to record an actual practice decision.

To use the example, ask your assistant to copy just this example folder into a new practice project. Do not work inside the public guide's repository when creating private team work.

Try asking: “Propose a warmer second headline on a new branch. Show the difference and help me request review.” Have another person review it, then record the agreed version in the decision log.
