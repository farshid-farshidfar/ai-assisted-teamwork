# AI-Assisted Teamwork

**Use VS Code, GitHub, and an AI assistant for everyday work. No coding knowledge needed to start.**

For designers, marketing teams, researchers, writers, and anyone who wants help organising a project, remembering changes, and reviewing work together.

You describe the work. Your assistant handles the technical steps it can perform and guides you through the clicks that need you. You review the result.

## Start with your usual AI chat

Copy this message into the AI assistant you already use. Include the address of this repository after the message.

```text
I have no technical background. Help me use this guide to set up VS Code
with one AI assistant, then Git and GitHub for my work.

Read README.md and START-HERE.md at the repository link below, then read
AI-GUIDE.md and follow its tutoring instructions. If you cannot open the
link or read those files, tell me which file to paste. Do not guess.

First ask whether I use Windows, Mac, or Linux, what I want to work on,
and which AI account I already have. Then give me ONE small action at a
time, tell me what success looks like, and wait for my reply.
Get me to a useful task with AI in VS Code before teaching team Git workflows.
Use official downloads. Explain costs before any paid signup.

Repository link: https://github.com/farshid-farshidfar/ai-assisted-teamwork
```

**A link is enough only if your assistant can read it.** If it cannot, open [AI-GUIDE.md](AI-GUIDE.md) here and paste its contents into the chat. It contains the teaching instructions and the next files to request. You do not need to download this guide to begin.

Prefer to follow the steps yourself? Open [Start here](START-HERE.md).

## What you will do

1. Install VS Code and either Codex or Claude Code.
2. Ask the assistant to create and improve a small practice document.
3. Install Git and save a named checkpoint of that document.
4. Put the practice project in a private GitHub repository.
5. Invite a colleague and practise reviewing a change.

Start alone with fictional information. The public repository you are reading is the **guide**; your team's working repository is a separate project and should start private.

## Why use these tools?

| Tool | What it contributes |
| --- | --- |
| VS Code | One place to open a project folder, edit text, and talk to an installed AI assistant. |
| AI assistant | Help drafting, organising, and carrying out technical tasks, subject to its access and permissions. |
| Git | Named checkpoints and a record of changes to files. |
| GitHub | An online place to share that history and review proposed changes. |

This workflow is especially useful for briefs, campaign copy, plans, research notes, and decisions stored as text. The [design-team example](docs/TEAMWORK.md) shows how it can sit alongside Figma, Adobe tools, and shared storage. It does not assume every team should replace its current tools.
